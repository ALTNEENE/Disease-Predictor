# Architecture

## Service Boundaries

The application is split into three deployable services.

## Frontend

React owns the user experience: authentication screens, upload flow, model training form, prediction form, dashboards, analytics, reports, and admin views. It talks only to the Express backend through REST APIs.

Key folders:

- `src/components` - reusable layout, charts, filters, states, and navigation.
- `src/pages` - feature pages.
- `src/context` - auth and language state.
- `src/services` - Axios API client.

## Backend

Express owns application security, persistence, file upload, report generation, dashboard aggregation, and communication with the ML service.

Key folders:

- `src/controllers` - HTTP handlers.
- `src/models` - MongoDB schemas.
- `src/services` - Excel analytics, ML client, PDF generation.
- `src/middleware` - auth, uploads, errors.
- `src/routes` - REST route modules.

The backend can compute analytics locally from Excel files. It also forwards datasets to the ML service for model-grade analysis and training.

## ML Service

FastAPI owns data science operations:

- Excel/CSV ingestion.
- Missing value handling.
- Categorical encoding.
- Numeric scaling.
- Train/test split.
- Decision Tree training.
- Metrics.
- Model persistence.
- Prediction.
- Tree text visualization.

The saved model bundle includes preprocessing pipelines, feature metadata, detected target columns, thresholds for risk scoring, and metrics.

## Data Flow

1. User uploads dataset in the frontend.
2. Backend saves the file and analyzes it.
3. Backend stores dataset metadata in MongoDB.
4. User starts training.
5. Backend streams the stored file to the ML service.
6. ML service trains Decision Tree models and saves the model bundle.
7. Backend stores the returned model metadata.
8. Predictions are sent through backend to ML service.
9. Reports are generated by backend as PDFs.

## Security

- JWT authentication.
- First registered user becomes admin.
- Role-based admin endpoint protection.
- Helmet security headers.
- CORS allowlist.
- Rate limiting.
- File extension and size validation.
- Password hashing with bcrypt.
